# Aurumfall

**Pobieranie gry:** wejdź w [Releases](https://github.com/Trzepak48/aurumfall/releases/latest) i pobierz **jeden plik: `Aurumfall.zip`**. Rozpakuj go i uruchom `Aurumfall.exe`.

`Aurumfall.exe` i `version.json` leżą w wydaniu tylko dla automatycznej aktualizacji — gra pobiera je sama, graczowi nie są potrzebne.

To repozytorium zawiera wyłącznie pliki wydań. Kod źródłowy jest prywatny.
